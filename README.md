# AI Virtual Tutor for ASEAN Rural Students

## 🌏 Objective
To create an AI-powered virtual tutoring platform that supports high school students in rural areas across ASEAN. This solution aims to reduce the educational gap by providing accessible, 24/7 academic support even in low-bandwidth regions.

## 🛠️ Current Progress
- ✅ Project initialized
- ✅ GitHub repository set up
- ⚙️ Working on backend logic and integration with an LLM (like OpenAI or Gemini)
- 🧠 Defined initial architecture plan for MVP
- ⏳ Frontend and database integration are in-progress

## 💡 Proposed Features
- LLM integration to act as a subject tutor
- Social login (Google/Facebook) for identity tracking
- Lightweight interface accessible via slow internet
- Expandable for other regions beyond ASEAN

## 🗺️ Deployment Plan
- MVP can be run on localhost
- Plans to deploy on a free-tier cloud provider (e.g., Render, Vercel, or Railway)

## 📌 Notes
This submission includes early development setup and planning. Due to time constraints, full implementation is still underway.

I am committed to continuing the project and refining it further beyond this submission.
